## ✨ Возможности

- ✅ **Создание товарных чеков** - интуитивный интерфейс для формирования чеков
- ✅ **База данных товаров** - хранение информации о товарах в локальной SQLite БД
- ✅ **Управление товарами** - добавление, редактирование, удаление товаров
- ✅ **Настройки компании** - хранение реквизитов и данных организации
- ✅ **Логотип компании** - загрузка и отображение логотипа на чеках
- ✅ **Печать чеков** - прямая печать на принтер
- ✅ **Сохранение настроек** - запоминание размеров окна и параметров
- ✅ **Автономная работа** - не требует интернета, все данные хранятся локально
- ✅ **Портативность** - один JAR файл со всеми зависимостями

## 💻 Требования

### Для использования (конечные пользователи)

- **Операционная система:** Windows 7/8/10/11
- **Java:** JRE 17 или выше
- **Память:** Минимум 256 МБ RAM
- **Место на диске:** ~50 МБ

### Для разработки

- **JDK:** 17 или выше
- **Maven:** 3.8+
- **IDE:** IntelliJ IDEA 2024+ (рекомендуется) или любая другая с поддержкой Maven
- **Git:** Для клонирования репозитория

## 🚀 Установка

### Вариант 1: Готовый релиз (рекомендуется)

1. Скачайте последний релиз:  [Releases](https://github.com/Artemka-devJava/FixByteBusi/releases/latest)

2. Распакуйте архив `FixByteBusi-v0.1.2.zip`

3. Установите Java 17+, если ещё не установлена: 
   - Скачать:  [Oracle JDK](https://www.oracle.com/java/technologies/downloads/) или [Adoptium](https://adoptium.net/)

4. Запустите приложение: 
   - **Двойной клик** на `Start.bat`
   - Или двойной клик на `FixByteBusi-0.1.2.jar`

### Вариант 2: Из исходников

```bash
# Клонировать репозиторий
git clone https://github.com/Artemka-devJava/FixByteBusi.git
cd FixByteBusi

# Собрать проект
mvn clean package

# Запустить
java -jar target/FixByteBusi-0.1.2.jar
